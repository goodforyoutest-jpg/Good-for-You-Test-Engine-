Generate MCQs with AI

Use any AI assistant (ChatGPT, Claude, Gemini) to instantly create MCQ question sets. Copy the ready-made prompt below, fill in your topic, and paste the result here.

1

Copy This Prompt

Paste this into any AI assistant. Replace [TOPIC], [SUBJECT], and [N] with your details:

You are an expert educator. Generate [N] MCQs for students studying [SUBJECT]. Topic: [TOPIC] Rules: - Each question must be exam-standard, clear and unambiguous - All 4 options must be plausible; only one is correct - Include a brief explanation for the correct answer - Cover different difficulty levels (easy, medium, hard) Return ONLY a valid JSON array. No preamble, no markdown, no extra text. [ { "section": "[TOPIC]", "q": "Question text?", "opts": ["Option A", "Option B", "Option C", "Option D"], "ans": 0, "exp": "Brief explanation of why the answer is correct" } ]
2

Required JSON Structure

Each question object must include these fields:

[ { "section": "Companies Act", "q": "What is the minimum paid-up capital for a private company?", "opts": ["Rs 1 Lakh", "Rs 5 Lakh", "No minimum", "Rs 10 Lakh"], "ans": 2, "exp": "After Companies (Amendment) Act 2015, no minimum paid-up capital is required." } ]
3

Upload or Paste the Output

Once the AI returns the JSON, either save it as a .json file and use the Upload tab, or paste the array directly in the Paste JSON tab.

4

Flexible Format Support

The engine also accepts alternate field names: question/q/text, options/opts/choices, answer/ans/correct, explanation/exp/note.
